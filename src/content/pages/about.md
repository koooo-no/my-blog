知序是一个专注于 **AI 量化研究、技术实践与个人知识管理** 的独立站。

## 这里记录什么

- **A 股市场分析** —— 结构、风格、资金与情绪
- **量化因子研究** —— 因子的构造、检验与失效
- **策略回测与风险控制** —— 从回测到组合，再到回撤管理
- **人工智能与大模型** —— 在研究和工程里的实际用法
- **自动化工具与个人项目** —— 把重复的事交给机器

## 我们怎么做

我们重视**数据、验证与复盘**。

不追逐未经证实的结论，不把回测成绩当作未来收益的保证，而是尽可能让每一项研究都有依据、
每一次实验都有记录、每一份知识都能持续积累。

## 目标

研究市场，探索技术，建立自己的认知体系。

**独立研究 · 持续实验 · 长期积累**

## 关于这个网站

用 [Astro](https://astro.build) 搭建的静态网站：没有后端、没有数据库、不需要服务器维护，
内容都是 Markdown 文件。构建出来就是一堆 HTML，托管在 GitHub Pages 上。

- 文章、笔记、作品分别放在 `posts` / `notes` / `projects` 三个板块
- 量化看板的数据来自本地研究项目的**冻结基线回测**，重建回测后脚本会自动同步
- 想了解技术细节，看[仓库](https://github.com/koooo-no/my-blog)里的 README
