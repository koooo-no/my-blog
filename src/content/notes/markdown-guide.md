## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 强调

```markdown
**加粗**
*斜体*
~~删除线~~
`行内代码`
```

## 列表

```markdown
- 无序项
- 无序项

1. 有序项
2. 有序项

- [ ] 待办事项
- [x] 已完成
```

## 链接和图片

```markdown
[链接文字](https://example.com)
![图片说明](/images/photo.jpg)
```

## 引用和代码块

````markdown
> 这是一段引用

```js
console.log('代码块');
```
````

## 表格

```markdown
| 列一 | 列二 |
| --- | --- |
| 内容 | 内容 |
```

## 分隔线

```markdown
---
```
